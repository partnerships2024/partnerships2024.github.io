If you want the **two posters to appear as large professional conference posters**, rather than ordinary cards, add the following CSS to your existing `styles.css`: ```css /* ========================= POSTER SHOWCASE ========================= */ .cards.two { display: grid; grid-template-columns: repeat(2, minmax(0, 1fr)); gap: 32px; } .poster-card { overflow: hidden; padding: 0; } .poster-image { width: 100%; background: #f4f6f8; overflow: hidden; } .poster-image img { display: block; width: 100%; height: auto; aspect-ratio: 4 / 5; object-fit: contain; transition: transform 0.35s ease; } .poster-card:hover .poster-image img { transform: scale(1.02); } .poster-content { padding: 28px; } .poster-content h3 { margin-top: 8px; margin-bottom: 12px; } .poster-content p { margin-bottom: 20px; } .poster-actions { margin-top: 20px; } /* ========================= MOBILE ========================= */ @media (max-width: 800px) { .cards.two { grid-template-columns: 1fr; } .poster-image img { aspect-ratio: auto; } } ``` This will make the two posters display **side-by-side on desktop and one above the other on mobile**, while preserving the same CHI Lab visual language as your Home and Symposium pages. If your two poster files are **PNG rather than JPG**, simply change `poster-1.jpg` and `poster-2.jpg` to the actual `.png` filenames.
