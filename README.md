## GitHub Pages deployment

1. Create or open the repository named `partnerships2024.github.io`.
2. Copy the contents of this project into the repository root.
3. Commit and push the files to the default branch.
4. In GitHub, open **Settings → Pages** and select the branch/root folder if Pages is not already enabled.
5. The site will be served from the GitHub Pages URL associated with the repository.

## Notes

- The supplied CHI Lab and ICRI-STE logos are included in `assets/` using the original uploaded files.
- No symposium date, schedule, venue, registration deadline, or publication list was invented because those details were not supplied.
- The publication and poster gallery pages are intentionally structured as expandable sections for accepted contributions.
- The website is responsive and uses plain HTML/CSS/JavaScript, so it can be hosted directly on GitHub Pages without a build process.
